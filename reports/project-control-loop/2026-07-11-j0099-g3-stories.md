  authority.

## Recommended pcl Commands

```sh
pcl story draft --feature F-0044 --actor "release reviewer" --goal "rely on one product-level CI decision across every maintained responsibility boundary" --expected-behavior "The product-gate succeeds only when node-runtime, schema-contract, speech-led-contract, repo-hygiene, editor-server, agent-definitions, and macos-studio all succeed; any failed, cancelled, or skipped required boundary prevents a passing product gate."

pcl story draft --feature F-0045 --actor "editor" --goal "retain a diagnostic preview without mistaking it for final-render or package approval" --expected-behavior "When QA fails, is skipped, or has no render, preview availability remains reported independently while final render and packaging are explicitly blocked and cannot acquire release authority."

pcl story draft --feature F-0046 --actor "operator" --goal "stop semantically invalid timeline and package artifacts before downstream use" --expected-behavior "Validation rejects duplicate timeline IDs, broken transition references, invalid caption or marker bounds, missing source-map assets, blocked editorial state, and failed package QA with actionable violations instead of accepting schema-shaped but unsafe artifacts."

pcl story draft --feature F-0047 --actor "local server consumer" --goal "consume source-map metadata and media URLs without receiving host filesystem capabilities" --expected-behavior "Source-map responses retain stable asset metadata and server-issued asset URLs while omitting local_source_path, link_path, and source_locator fields."

pcl story draft --feature F-0048 --actor "local server consumer" --goal "list usable projects and check server health without learning the host filesystem layout" --expected-behavior "Neither GET /api/projects nor GET /api/health may expose absolute filesystem paths; project IDs, timeline-availability state, and health status remain stable and usable, and any serialization path that would disclose an absolute path must omit or replace that field."

pcl story draft --feature F-0049 --actor "editor" --goal "use waveform and audio-cue timeline overlays unchanged after visual-layer extraction" --expected-behavior "The extracted overlay boundary preserves waveform and cue layout, accessibility identifiers, command routing, interaction behavior, and canonical artifact contracts."

pcl story draft --feature F-0050 --actor "maintainer" --goal "identify the current executable architecture and operating authority without relying on superseded proposals" --expected-behavior "The current architecture, decisions, pipeline states, security model, release checklist, and deprecation inventory are documented together and explicitly take precedence over historical design documents."
```
