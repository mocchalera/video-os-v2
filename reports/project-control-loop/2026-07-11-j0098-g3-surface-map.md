# G-0003 governance surfaces are implemented, with one API path-redaction gap

## Findings

- All eight linked tasks (`T-0001`–`T-0008`) are done and the seven goal
  criteria have implementation evidence in `E-0189`–`E-0193` and
  `E-0236`–`E-0238`.
- Canonical pipeline ownership is implemented by `runtime/pipeline/plan.ts`,
  `runtime/pipeline/executor.ts`, and the thin `scripts/full-pipeline.ts`
  adapter (`F-0042`, `F-0043`, `T-0001`).
- Responsibility-scoped CI and its aggregate product gate are implemented in
  `.github/workflows/ci.yml` (`T-0002`), but the whole gate lacks one concrete
  feature record.
- Preview availability is separated from final/package authority by
  `scripts/editorial-pipeline.ts`,
  `schemas/editorial-pipeline-status.schema.json`, and
  `runtime/packaging/gate10.ts` (`T-0003`).
- Semantic validation beyond JSON Schema is implemented in
  `runtime/validation/schema-validator.ts` and
  `scripts/validate-schemas.ts` (`T-0005`).
- Source-map capability fields are redacted and real paths are authorized by
  `editor/server/index.ts` and `editor/server/utils.ts` (`F-0039`, `T-0004`).
- One adjacent runtime gap remains: `GET /api/projects` returns an absolute
  `path`, and `GET /api/health` returns the absolute `projectsDir`
  (`editor/server/index.ts`). These responses violate the goal's broader
  no-absolute-path API boundary even though source-map responses are redacted.
- Native Studio is the canonical operator surface; its menus, project form,
  Agent job write contracts, compile gates, and render/package gates are
  implemented. `editor/server` is supported independent infrastructure and
  `editor/client` is retired (`F-0036`, `T-0007`).
- The Studio decomposition plan and first audio-overlay view extraction are
  complete (`T-0006`, `E-0236`). The six current-truth architecture and
  operating documents are complete (`T-0008`, `E-0238`).
- Existing features cover important parts of G-0003, but the workflow found no
  goal-level stories, tests, verification, or feature records for several
  already-implemented governance capabilities.
