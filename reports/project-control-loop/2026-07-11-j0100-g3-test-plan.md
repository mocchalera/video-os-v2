# Seven focused G-0003 governance test plans are ready

## Findings

- `F-0044` needs an acceptance check that the aggregate `product-gate` rejects
  every non-success required-job result.
- `F-0045` already has unit coverage in
  `tests/editorial-pipeline-status.test.ts` and `tests/m4-qa.test.ts`.
- `F-0046` already has semantic-invalidity coverage in
  `tests/validate.test.ts`.
- `F-0047` has helper coverage in
  `tests/editor-server-media-roots.test.ts`, but warrants route-level
  source-map response coverage.
- `F-0048` has no endpoint regression and remains `needs_fix`. The integration
  must call `GET /api/projects` and `GET /api/health`, preserve stable useful
  fields, and recursively reject absolute paths, known repository prefixes,
  and the current `path` / `projectsDir` keys.
- `F-0049` is covered by the `VideoOSStudio` target build plus the full Swift
  suite.
- `F-0050` warrants a permanent documentation-contract check for the six
  current-truth files, local links, cited executable paths, precedence, and
  repo hygiene.

## Recommended pcl Commands

```sh
pcl test plan --feature F-0044 --type acceptance --scenario "Execute .github/workflows/ci.yml product-gate with all seven required jobs successful, then exercise failed, cancelled, and skipped required-job results across node-runtime, schema-contract, speech-led-contract, repo-hygiene, editor-server, agent-definitions, and macos-studio." --expected "product-gate passes only when every required result is success; any failed, cancelled, or skipped boundary exits nonzero and reports that the product gate is blocked."

pcl test plan --feature F-0045 --type unit --scenario "Run npm test -- tests/editorial-pipeline-status.test.ts tests/m4-qa.test.ts and cover QA failure with an existing preview, skipped QA with no render, successful QA, unresolved fatal review issues, and explicit creative override." --expected "Preview availability remains independent; failed, skipped, or renderless QA blocks final render and packaging with stable reasons, successful QA leaves both not_requested, and only an explicit creative_override bypasses fatal-review package blocking."

pcl test plan --feature F-0046 --type unit --scenario "Run npx vitest run tests/validate.test.ts against duplicate track/clip/transition IDs, broken transition references, missing source-map assets, invalid caption and marker bounds, blocked editorial status, failed package QA, and valid captions at a nonzero timeline start." --expected "Every unsafe schema-shaped artifact produces its actionable semantic rule violation, while valid absolute caption frames at the inclusive timeline boundary remain accepted."

pcl test plan --feature F-0047 --type integration --scenario "Exercise the editor-server app/router for GET /api/projects/:id/source-map using an item containing local_source_path, link_path, and source_locator; also request an invalid project ID and a project without a source map, reusing tests/editor-server-media-roots.test.ts helper fixtures." --expected "The success response preserves stable asset metadata and /api/projects/:id/media/by-asset/:assetId URLs while recursively omitting capability-path fields and absolute paths; invalid IDs return 400 and missing source maps return 404 without disclosing host paths."

pcl test plan --feature F-0048 --type integration --scenario "Start the preview server or instantiate its exported app/router against a temporary projects container containing one timeline project and one non-project directory, then call GET /api/projects and GET /api/health and recursively inspect both JSON payloads." --expected "GET /api/projects retains stable id, name, and hasTimeline fields and excludes the non-project directory; GET /api/health retains status ok and a parseable timestamp; no key or nested string exposes path or projectsDir, any absolute POSIX or drive-letter path, path.resolve('.'), the resolved projects container, the fixture project root, or known /Users/ and /home/ repository prefixes."

pcl test plan --feature F-0049 --type smoke --scenario "Run swift build --target VideoOSStudio && swift test after compiling TimelineWaveformOverlay and TimelineAudioCueOverlay from TimelineAudioOverlayViews.swift through their unchanged TimelineViews.swift call sites." --expected "The target builds and the Swift suite passes with unchanged overlay layout inputs, help text, accessibility identifiers, command routing, and artifact contracts; broken module visibility, call sites, or identifiers fail the smoke."

pcl test plan --feature F-0050 --type acceptance --scenario "Run a focused current-truth documentation contract test over README.md, ARCHITECTURE.md, docs/CURRENT_ARCHITECTURE.md, docs/DECISIONS.md, docs/PIPELINE_STATES.md, docs/SECURITY_MODEL.md, docs/RELEASE_CHECKLIST.md, and docs/DEPRECATED.md, followed by npm run verify:repo." --expected "All six authoritative documents exist, local links resolve, referenced executable/schema/CI paths exist, README and ARCHITECTURE navigate to them, and DEPRECATED records the precedence order; missing files, broken targets, historical-authority ambiguity, or repository-hygiene violations fail."
```
