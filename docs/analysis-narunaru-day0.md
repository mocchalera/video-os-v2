## 3. バズるSNS縦型動画の編集技法・構成要素

### ① カットテンポと画面変化のリズム
- **平均1.9秒ごとの画面変化**: トークが続く場面でも、同一構図を2.5秒以上続けない。
- **パンチイン / パンチアウトの活用**: 同一テイクのトークでも、強調したい単語（「証明したい」「諦めません」）の瞬間に 1.15〜1.25倍 の寄りカットへジャンプカット。
- **マルチレイヤー素材構成（A-roll + 4種のB-roll/インサート）**:
  - A-roll: メインロケ地（砂浜）での語り
  - B-roll (Action): 走っている姿（屋外、トラック、砂浜）
  - B-roll (Enactment): 再現ドラマ（椅子の脚に足をぶつける）
  - Evidence (Photos): レントゲン写真、怪我の包帯写真
  - Archival (Past Video): マラソン大会の本番動画

### ② テロップ（字幕）のタイポグラフィと配置
- **視認性とセーフエリア**:
  - 画面中央（センター〜やや下部）に配置。SNSの右側アイコン群（いいね、コメント、シェア）や下部アカウント名・キャプション領域に一切被らない。
  - 改行は意味のまとまりで適切に2行以内（1行4〜10文字程度）。
- **スタイリングルール**:
  - ベース: 視認性の高い極太角ゴシック（Noto Sans JP 900 / 各種太字フォント）、白文字＋黒ストローク＋ソフトシャドウ。
  - 感情ハイライト:
    - ポジティブ・最重要フック: 黄色グラデーション＋黒ストローク
    - ネガティブ・衝撃・怪我: 赤黒グラデーション、亀裂/ダメージ装飾フォント
    - キーワード強調: フォントサイズ1.3〜1.5倍

### ③ 音響（Audio & SE）設計
- **トーク音声（Voice Clarity）**: 音声はクリアにMAされており、コンプレッサーとEQで前に出るミックス。
- **効果音（SE）の厳密な同期**:
  - テロップの出現、写真のインサート、感情の転換点に必ず「ドン」「シュッ」「ピコッ」「バキッ」といったSEをジャストで配置。
- **プラットフォームBGM戦略**:
  - 編集段階でBGMを焼き込まないことで、Instagram / TikTok / YouTube Shortsで投稿時にトレンド楽曲を付与可能。

## 4. Video OS (RoughCut Agent) への実装・再現方針

このクオリティとストーリーテリングを自動／半自動で再現するために、Video OSに必要なコンポーネント・機能：

1. **新スキル `finish-creator-short` / `creator-story-short`**:
   - 既存の `finish-business-short`（講義・ビジネス向け）とは別に、**クリエイター・挑戦・Vlog・共感創出型SNS縦型ショート専用のスキル**を新設。
2. **ストーリーアーク・ブループリント・テンプレート**:
   - `Hook (0-2s)` -> `Identity (2-5s)` -> `Past & Struggle (5-15s)` -> `Breakthrough (15-25s)` -> `Crisis/Pinch (25-40s)` -> `Philosophy & Goal (40-60s)` -> `CTA/Community (60-75s)` の黄金構成パターンを構造化。
3. **マルチレイヤー素材アロケーション（素材の自動種別分類と配分）**:
   - トーク（A-roll）
   - 実景・ランニング・作業（B-roll）
   - 証拠写真（Evidence: レントゲン、写真、スクショ）
   - 再現・インサート
4. **感情連動テロップ＆エフェクトエンジン**:
   - 通常テロップ vs 感情別ハイライトテロップ（Yellow Pop, Red Impact/Damage, Focus Zoom）の自動適用ルール。
5. **SE（効果音）自動アセットマッピング**:
   - テロップの種別（Hook, Crisis, Punchline, CTA）に応じたSEトラックの自動配置。
