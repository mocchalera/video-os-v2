# RoughCut Agent v0.2.0

Status: release candidate prepared on 2026-07-22. This version has not been
tagged or published to the public repository.

## Highlights

- Unified the video pipeline around shared phase execution, canonical artifact
  ownership, and one full-pipeline contract used by runtime entrypoints and
  Agent Skills.
- Added truthful analysis, planning, rendering, and freshness checks for audio,
  still images, and image sequences.
- Added Editorial Eye observation, relation-aware cut evaluation, benchmark
  contracts, and safer QA source discovery and mutation rollback.
- Expanded VideoOSStudio with caption and BGM review, editorial preference
  memory, render routing, package preflight, and end-to-end package contract
  verification.
- Hardened publication preflight, source-input attestation, package provenance,
  render-duration accounting, and stale-result protection.
- Added deterministic Remotion / HyperFrames routing, bundled Japanese fonts,
  and reusable social/interview finishing paths.

## Compatibility and behavior changes

- Node.js 22.x and npm 10.x remain required.
- The npm package remains `private`; v0.2.0 is a repository release, not an npm
  registry publication.
- Package success now requires current hashes and provenance for canonical
  timeline, QA, state, render inputs, and produced files. A worker exit code by
  itself is not sufficient.
- Canonical full-pipeline output includes `09_output/rough-cut.mp4`.
- Optional local-model paths remain fail-open, while release and package claims
  fail closed when required evidence is missing or stale.

## Public repository boundary

The published tree contains only `projects/_template/`, `projects/demo/`, and
`projects/sample/` under `projects/`. Source footage, generated renders,
checkout-local evaluation output, and private project artifacts are excluded.
`npm run verify:repo` enforces this allowlist.
